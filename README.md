- Traditional accounts

- Transactions

BankAccount

Main

A collection of custom Java implementations exploring fundamental data structures and algorithms.

### Linear Structures

`Linked Lists` · `Stacks` · `Queues` · `Priority Queues` · `Sorted Lists` · `Sorting`

`Binary Trees` · `BST` · `AVL` · `Red-Black Trees` · `Heaps` · `Graphs`

- Tree traversal
- Recursion
- Height and depth
- Lowest common ancestor

- Successor and predecessor
- Tree deletion

## Tic-Tac-Toe

<img src="https://img.shields.io/badge/CONSOLE-7C3AED?style=flat-square">
<img src="https://img.shields.io/badge/SWING%20GUI-0F172A?style=flat-square">

<br>

A Tic-Tac-Toe implementation developed through two versions, moving from a console-based application to a graphical Java Swing interface.

### Version 1

**Console**

- Configurable board
- Player input
- Input validation
- Win detection
- Draw detection

### Version 2

**Java Swing**

- Graphical board
- Mouse interaction
- Configurable board size
- Win detection
- Draw detection
- Winning-line visualisation
- GUI dialogs

### Progression

```text
Console Logic
      ↓
Game State
      ↓
Object-Oriented Design
      ↓
Swing Interface
```
